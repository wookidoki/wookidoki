## 이승욱

건설 PMIS(Oracle Primavera Unifier) 구축과 운영을 하고 있습니다.
업무 밖에서는 웹 서비스, 데이터 분석, 게임을 만듭니다.

포트폴리오 사이트: https://wookidoki.github.io

### 업무

- Unifier 비즈니스 프로세스(BP) 설계, REST API 연동, 데이터 이관, BI Publisher 리포트
- 반도체 FAB 건설 현장 시스템 운영 (계정·권한, 공수 집계 리포트, 출입·장비 시스템 API 연동)
- AWP(CWA·CWP·IWP) 데이터와 3D 모델을 연결한 진척 관리 웹앱 개발
